# RESOURCES.md Format

`RESOURCES.md` is a small set of reusable, high-trust primary sources.

```markdown
# Backend Engineering Resources

| Topic | Source | Use when |
| --- | --- | --- |
| Spring transactions | [Official Spring documentation](https://docs.spring.io/) | Framework behavior must be distinguished from repository convention |
```

Prefer official documentation, specifications, framework source, and observed repository behavior. Annotate when a source is useful, remove shallow or obsolete entries, and record gaps rather than filling the file with generic links.
