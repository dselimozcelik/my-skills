# Session Record Format

Session records live in `sessions/` and contain sanitized learning evidence from one real task.

```markdown
# YYYY-MM-DD — <portable task type>

## Concepts exercised
- ...

## Evidence produced by the learner
- ...

## Misconception or gap
- ...

## Mastery changes
- <concept>: <old> → <new>, because ...

## Next retrieval opportunity
- ...
```

Never include company names, repository paths, code, schemas, payloads, credentials, or production values.
