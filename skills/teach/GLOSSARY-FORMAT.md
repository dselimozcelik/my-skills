# GLOSSARY.md Format

`GLOSSARY.md` contains compressed definitions only after the learner has demonstrated correct use of the term.

```markdown
# Backend Engineering Glossary

## Spring

**Dependency injection:**
The container supplies an object's required collaborators instead of the object constructing them itself.

**Transaction boundary:**
The business-operation boundary within which database changes commit or roll back as one unit.
```

Keep definitions to one or two causal sentences. Group terms when useful, note ambiguous local usage, and revise definitions as understanding deepens. Never use the glossary as initial teaching material or copy proprietary names into it.
