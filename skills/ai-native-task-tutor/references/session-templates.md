# Session Templates

Use only the smallest template needed at the current checkpoint. Keep teaching tied to repository evidence.

## Shared task model

```markdown
## Current behavior
Entry → important boundaries → side effect

## Desired behavior
Change: ...
Acceptance criteria: ...
Out of scope: ...

## Open questions
- Evidence: ...
- Inference/uncertainty: ...
```

## Implementation-and-learning plan

```markdown
### Step 1 — [behavior/boundary]
Code area: ...
Why this step is ordered here: ...
Concept needed: ...
Repository example: ...
Implementation: ...
Focused verification: ...
Learner checkpoint: ...
```

## Local step loop

```markdown
Step: ...
Existing code/example: ...
Prediction question: ...?
Missing causal link: ...
Minimal lesson: ...
Implementation/diff: ...
Verification and its limit: ...
Updated end-to-end flow: ...
Step understanding: demonstrated | in progress
```

## Digital Worker diff replay

```markdown
Plan step: ...
Actual changed hunks: ...
Matches plan: yes | partly | no
Unexpected or missing behavior: ...
Concept needed to inspect it: ...
Existing repository comparison: ...
Local validation: ...
Learner explanation: ...
Step understanding: demonstrated | in progress
```

## Final synthesis

Ask one question at a time without supplying the answer:

```markdown
1. End-to-end flow: ...?
2. Key mechanism/decision: ...?
3. Failure and observable signal: ...?
```

If an answer is incomplete:

```markdown
Reopened plan step: ...
Missing causal link: ...
Smallest corrective lesson: ...
Changed retest question: ...?
```
