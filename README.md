# Prompt Kütüphanem

Öğrenmek için kullandığım prompt'lar. Kopyala, `[KÖŞELİ PARANTEZ]` olan yerleri doldur, yapıştır.

Amaç: AI'ı cevap makinesi olarak değil, beni aktif tutan bir hoca ve reviewer olarak kullanmak.

## Kurallarım

1. **AI, benim yazabileceğim şeyi yazabilir. Yazamayacağım şeyi yazamaz.**
2. **Önce ben denerim.** 15-30 dakika takılmadan yardım istemem.
3. **Anlamadığım kodu merge etmem.**
4. **Derinleşmeli miyim?** Bunu 2-3 cümleyle anlatabiliyor muyum? Şu anki işimde lazım mı? Anlatamıyorsam veya lazımsa derinleşirim, yoksa geçerim. Yanlış karar verirsem sonra geri dönerim.
5. **Bunaldığımda:** listenin tamamına değil, sadece sıradaki maddeye bakarım.
