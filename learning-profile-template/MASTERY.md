# Mastery

Levels:

- `0 — unverified`: no demonstrated evidence yet
- `1 — explain`: can explain the central mechanism with light prompting
- `2 — apply`: can apply and verify it in a real task
- `3 — debug/review/teach`: can diagnose, review, transfer, or teach it causally

Do not raise a level for exposure, generated code, a green build, or “I understand.” Store only sanitized evidence.
